# Contexto de lo que se hizo en el proyecto
Desarrollamos una página de inventario sencilla con funcionalidades CRUD:

- Agregar productos
- Listar productos
- Editar productos
- Eliminar productos

El sistema se conecta a una base de datos MySQL mediante Spring Boot y utiliza Axios para realizar las peticiones HTTP entre el frontend y el backend.

Además, los identificadores (ID) de los productos no se reutilizan después de eliminar registros, ya que MySQL maneja automáticamente los valores `AUTO_INCREMENT` para evitar conflictos e inconsistencias en la base de datos.
